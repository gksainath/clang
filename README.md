# C Programming Repository (`clang`)

A well-structured collection of C programs covering fundamentals, data structures, algorithms, pointers, memory management, file handling, and mini-projects/games.

---

## 📂 Repository Directory Structure

```
clang/
├── 01_basics_and_fundamentals/      # Basic syntax, control flow, loops & arithmetic operations
├── 02_strings/                      # String manipulations & custom string helper functions
├── 03_structures_and_unions/        # Structs and Unions usage
├── 04_pointers_and_memory/          # Dynamic Memory Allocation (calloc, malloc, free)
├── 05_file_handling/                # File reading and writing operations
├── 06_data_structures/              # Data Structures implementations
│   ├── linked_lists/                # Singly, Doubly, Circular Linked Lists & operations
│   ├── stacks/                      # Array and Linked List Stack implementations & applications
│   ├── queues/                      # Linear, Circular, Linked List, and Double-ended Queues
│   ├── trees/                       # Binary Search Tree (BST) operations & traversals
│   └── hashing/                     # Collision handling using Linear Probing
├── 07_algorithms/                   # Core Searching and Sorting Algorithms
│   ├── searching/                   # Linear Search & Binary Search
│   └── sorting/                     # Bubble Sort, Insertion Sort, Selection Sort
└── 08_mini_projects_and_games/      # Interactive CLI applications and games
```

---

## 📁 Categorized File Index

### 01. Basics & Fundamentals (`01_basics_and_fundamentals/`)
- `first.c`: Basic Hello World program
- `months.c`: Switch-case month identifier
- `multiplication.c`: Basic arithmetic multiplication logic
- `vowels.c`: Vowel counting / conditional checks

### 02. Strings (`02_strings/`)
- `string.c`: Standard string operations
- `check_string_palindrome.c`: Palindrome string checker
- `stringconcatination_withoutlibfile.c`: String concatenation without standard library functions
- `stringcopy_usingpointers.c`: String copying using raw pointers

### 03. Structures & Unions (`03_structures_and_unions/`)
- `structureandunion.c`: Structures vs Unions implementation and comparison

### 04. Pointers & Memory Management (`04_pointers_and_memory/`)
- `calloc_studentmarks.c`: Dynamic array allocation for student marks using `calloc`

### 05. File Handling (`05_file_handling/`)
- `textfile_read_write.c`: Reading from and writing to text files using file pointers (`FILE*`)

### 06. Data Structures (`06_data_structures/`)
- **Linked Lists (`linked_lists/`)**: `linkedlist.c`, `circularlinkedlist.c`, `doublylinkedlist.c`, `remove_duplicates_sll.c`, `reverse_sll.c`, `polynomial_add_subtract.c`
- **Stacks (`stacks/`)**: `stacksusingarray.c`, `stacksusinglinkedlist.c`, `infixtopostfix.c`, `postfix.c`, `check_balanced_parenthsis.c`, `reverse_using_stack.c`
- **Queues (`queues/`)**: `queue_arrays.c`, `queue_ll.c`, `circularqueue.c`, `dqueue.c`
- **Trees (`trees/`)**: `binarysearchtree.c`
- **Hashing (`hashing/`)**: `linearprobing.c`

### 07. Algorithms (`07_algorithms/`)
- **Searching (`searching/`)**: `linearsearch.c`, `binarysearch.c`
- **Sorting (`sorting/`)**: `bubblesort.c`, `insertionsort.c`, `selectionsort.c`

### 08. Mini Projects & Games (`08_mini_projects_and_games/`)
- `atm.c`: Console-based ATM machine simulator
- `librarymanagement.c`: Library books management system
- `numberguessgame.c`: Random number guessing game
- `rps.c`: Rock, Paper, Scissors game
- `snakegame.c`: Classic terminal Snake game
